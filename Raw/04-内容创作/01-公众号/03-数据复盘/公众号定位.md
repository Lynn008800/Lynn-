## 二、定位：从"高考志愿填报师"到"人本主义学业规划师"

### 核心差异化

区别于普通高考志愿填报师：
- **不只是填报志愿那一环**，而是覆盖从选科到录取的全周期
- **人本主义导向**：了解学生的性格特质和能力，帮助找到适合的方向
- **体系化内容**：有完整的学业规划框架，不是零散的信息搬运
- **专注广东省**：高考政策分省，聚焦广东更精准、更实用

### 核心理念

> 适合的才是最好的 —— 不是追热门专业，而是帮每个孩子找到适合自己的方向。

---

## 三、目标受众

**核心受众：广东省高一、高二、高三的家长和学生**

将受众前移的理由：
- 高三家长只在6-7月集中关注，之后流失
- 高一高二家长是长期用户，可以从选科阶段开始陪伴
- 提前建立信任，到高三填报时自然转化
- 学生也会主动搜索学习方法、专业认知类内容

### 【认识自己】— 帮孩子看清性格、能力、兴趣

规划的第一步。孩子不知道自己适合什么，后面的选科选专业都是盲选。

| 细分方向 | 说明 | 示例选题 |
|---------|------|---------|
| 性格与专业匹配 | 不同性格适合什么方向 | ISTJ型适合什么专业？一个自查清单 |
| 能力优势发现 | 成绩之外，孩子真正擅长什么 | 成绩单上看不见的5种隐藏优势 |
| 兴趣探索 | 不知道喜欢什么怎么办 | 孩子说没兴趣？可能是没试过：3步体验法 |
| 价值观澄清 | 选安稳还是选热爱 | 帮孩子想清楚"什么对我最重要" |
| 测评工具科普 | MBTI、霍兰德等怎么用 | 霍兰德、MBTI、多元智能：哪个对选专业真有用？ |

### 【选科专业认知】— 选科怎么选、专业学什么、未来干什么

| 细分方向 | 说明 | 示例选题 |
|---------|------|---------|
| 选科组合策略 | 不同组合的利弊和适配方向 | 物化生vs物化地：两种组合对应完全不同的专业池 |
| 专业深度解读 | 把专业掰开揉碎讲清楚 | 心理学到底学什么？四年课程表+8条真实出路 |
| 院校认知 | 广东省内+省外值得关注的学校 | 广东家长容易低估的5所双非好校 |
| 行业与职业趋势 | 读完出来能干什么、前景怎么样 | AI时代，哪些专业反而更值钱了？ |

### 【政策解读】— 广东省高考的游戏规则

家长最焦虑、也最容易踩坑的一块，独立成维度后更聚焦。

| 细分方向 | 说明 | 示例选题 |

| 广东选科政策 | 3+1+2怎么玩 | 一张图看懂：广东新高考选科全流程 |
| 赋分制 | 等级分到底怎么算 | 赋分制拆解：选哪科更划算？用数据说话 |
| 志愿填报规则 | 平行志愿的底层逻辑 | 冲稳保怎么排？广东45个平行志愿一次讲清楚 |
| 多元升学路径 | 高考之外的路 | 综评、强基、港澳升学：广东考生还有这5条路 |
| 政策变动跟踪 | 新政策来了意味着什么 | 2026广东本科专业目录调整：选科要求变了哪些 |

### 【学会学习】— 方法对了，努力才有用

2026-07-28 新增维度。基于应用心理硕士的专业背景，提供有科学依据的学习方法论。

| 细分方向 | 说明 | 示例选题 |
|---------|------|---------|
| 记忆方法 | 基于心理学的有效记忆策略 | 背了又忘？间隔重复法：被验证最高效的记忆方式 |
| 专注力训练 | 实用工具和方法 | 每天15分钟舒尔特方格，专注力真的能涨吗 |

| 考试策略 | 考场上的技术活 | 丢分最多的不是不会做，是审题和检查这两个习惯 |

### 发布节奏与标题格式

- **频率：** 每周1篇，固定时间（如周三晚或周六上午）
- **轮换：** 五大维度轮流发布
- **标题格式：** `【维度名】` + 具体标题，如 `【学会学习】每天15分钟舒尔特方格，专注力真的能涨吗`
- **引流：** 每篇文末引导加微信 / 进家长交流群
