# PCOS 月经调理与促排卵方案

> 2026年7月咨询记录：月经量极少调理 + 促排卵综合方案

## 当前情况

- 周期：上周期结束到本次来潮约40天（在正常40-50天范围内，偏短）
- 本次出血：已持续5天，量极少，部分日子几乎一整天没有
- 可能诱因：7月中旬拔智齿，手术应激反应干扰排卵窗口期
- 判断：无排卵周期导致撤退性出血（非真正月经），一次性偶发事件

## 肌醇（Myo-inositol）详解

### 是什么

维生素B族类似物，营养补充剂，非激素药物。天然存在于水果、豆类、谷物中。

### 作用原理

PCOS核心链条：胰岛素抵抗 → 卵巢过度响应胰岛素信号 → 雄激素分泌失控 → 卵泡发育受阻、排卵困难

肌醇作为胰岛素的"第二信使"辅助信号传递，改善细胞对胰岛素的敏感性 → 血液胰岛素水平下降 → 卵巢不被过度刺激 → 雄激素下降 → 卵泡正常发育并排卵 → 黄体形成 → 孕酮分泌 → 子宫内膜正常增厚 → 月经量和周期恢复正常

### 疗效数据

| 指标 | 有效率 |
|------|--------|
| 恢复排卵 | 约70-75% |
| 改善月经周期 | 约60-70% |
| 降低游离睾酮 | 约60-80% |

### 用法

- 剂量：每天2000-4000mg，从2000mg起步
- 服用方式：分两次，随餐服用
- 起效时间：2-3个月
- 试周期：3个月后评估效果，无效可停
- 购买建议：纯Myo-inositol粉剂，不需要含D-chiro-inositol的40:1复方

## 综合调理方案

### 饮食

核心原则：稳血糖（不是少吃，是吃对）

**早餐蛋白质要足**
- 先吃鸡蛋/豆腐/豆浆/酸奶，再吃主食
- 蛋白质至少占早餐的30%
- 避免纯碳水早餐（粥、包子、面包、麦片）

**主食替换**
- 白米饭掺1/3糙米/燕麦/荞麦/藜麦，或杂粮饭预拌包
- 不戒碳水，瘦多囊不吃碳水容易掉体重

**戒液体糖**
- 奶茶、果汁、含糖饮料是影响最大的单一因素
- 液糖吸收太快，对胰岛素冲击最大
- 偶尔喝可以，不能成日常

**抗炎脂肪**
- 每天一小把核桃或一勺亚麻籽粉（Omega-3抗炎）
- 做菜用橄榄油/山茶油，少用大豆油/玉米油/葵花籽油（Omega-6促炎）
- 蓝莓、草莓、树莓（花青素抗炎，升糖低）

**十字花科蔬菜**
- 西兰花、卷心菜、羽衣甘蓝
- 含有吲哚-3-甲醇（I3C）和二吲哚甲烷（DIM），帮助肝脏代谢多余雄激素和雌激素
- 频率：每周3-4次

**关于豆浆**
- 豆浆含大豆异黄酮（植物雌激素），但活性极低（人体雌激素的千分之一到万分之一）
- PCOS不缺雌激素（通常正常或偏高），缺的是排卵后的孕酮
- 结论：作为植物蛋白来源可以喝，但不能调月经、促排卵

### 补充剂优先级

**第一梯队**
1. 肌醇（Myo-inositol）：每天2000mg起，分两次随餐
2. 维生素D：PCOS女性缺乏率超70%，检查25-羟维生素D，低于30ng/ml就补，每天1000-2000IU + 日晒15-20分钟

**第二梯队**
3. Omega-3（鱼油）：如果每周吃深海鱼少于2次，每天EPA+DHA合计1000-2000mg
4. 锌：正常饮食一般够，主要来自豆类、坚果、瘦肉、贝类

**第三梯队**
5. NAC（N-乙酰半胱氨酸）：如果肌醇半年效果不明显再考虑
6. 薄荷茶：每天两杯留兰香茶，降低游离睾酮

### 运动

瘦多囊运动策略与胖多囊不同——增肌优先于减脂。

| 类型 | 频率 | 时长 | 说明 |
|------|------|------|------|
| 力量训练 | 每周2次 | 20-30分钟 | 优先于有氧，增肌改善胰岛素敏感性 |
| 饭后散步 | 每天午晚餐后 | 各10-15分钟 | 性价比最高，比集中运动对血糖影响更大 |
| 有氧运动 | 保持现有节奏（一三五） | 每次不超过30分钟 | 避免长时间高强度刺激皮质醇 |
| 瑜伽/拉伸 | 每周1-2次 | 睡前10分钟 | 压皮质醇，改善盆腔血供 |

### 睡眠

- 规律性比总时长更重要
- 目标：每晚10:30-11:00睡觉，早上固定时间起床
- 原理：昼夜节律通过褪黑素-下丘脑-垂体-卵巢轴直接影响排卵

## 执行优先级

**第一梯队（马上开始）**
- 肌醇每天2000mg
- 早餐加蛋白质
- 戒液体糖
- 饭后散步

**第二梯队（第一梯队稳定后）**
- VD检查+补充
- 杂粮饭替代白米饭
- 十字花科蔬菜每周3-4次
- 每周2次力量训练

**第三梯队（前两梯队稳定后再加）**
- 鱼油
- NAC
- 薄荷茶

> 不用一次性全部做到，选能落地的先开始。
