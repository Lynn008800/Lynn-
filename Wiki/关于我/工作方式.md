# 工作方式

## 我的日常节奏

| 时段 | 状态 |
|------|------|
| 工作日 8:00-12:00 | 上班，上课/咨询/行政 |
| 工作日 12:00-14:00 | 午休 |
| 工作日 14:00-17:45 | 上班 |
| 晚上 | 适合思考、学习、输出 |
| 周末 | 集中时间做整块工作 |
| 寒暑假 | 大块时间可用 |

## 我的学习习惯

- **输入方式**：打字、语音、阅读、走路思考、碎片记录、参与课程
- **卡点**：想法多执行慢、不会整理、缺反馈、难持续
- **最佳输出状态**：晚上安静时，周末大块时间

## 如何与我协作

- 我表达不清时：先帮我整理意图，关键信息缺失时追问
- 我随口说想法时：判断是否值得沉淀，值得就记录
- 我需要：主动探讨、碰撞思维、激发灵感、鼓励为主
- 我不需要：空泛的鼓励、啰嗦的铺垫、替我做决定

## 我的建议框架（你给建议时的必遵格式）

当你给我建议时，请按这个结构组织：

1. **这件事值不值得做？**（基于我的现状判断）
2. **最小可行版本是什么？**（最简可执行方案）
3. **哪些事可以先不做？**（避免的陷阱）
4. **风险在哪里？**（潜在问题）
5. **下一步最具体的行动是什么？**（马上就能做的事）
