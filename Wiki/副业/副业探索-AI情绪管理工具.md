# 副业探索：AI情绪管理网页工具 · 开发记录

> 2026-07-22 完成 MVP V1 开发

## 文件清单

| 文件 | 说明 |
|------|------|
| `index.html` | 主页面结构，5个页面（首页/问卷/结果/情景练习/情绪日记） |
| `style.css` | 完整样式，移动端优先，暖色调，圆角卡片风格 |

## 功能清单

- **情绪自查问卷**：12道选择题，覆盖11种情绪，根据答案匹配主要情绪并显示建议
- **结果反馈页**：显示主要情绪 + 应对策略 + 通用评语 + 警示提示
- **7个情景练习**：考试焦虑、同桌冲突、被老师批评、摔倒被笑、爸妈吵架、友情危机、嫉妒情绪
- **情绪日记**：六格结构（日期/心情指数/情绪/事件/感受/应对/明日计划），localStorage 持久保存
- **免费无墙**：无需注册登录，打开即用

## 部署

目前只能本地打开使用。如需部署到 GitHub Pages 让其他人访问，步骤：
1. 在 GitHub 新建一个空仓库（如 `mood-station`）
2. 在本目录执行：
```
git init
git add .
git commit -m "initial commit"
git remote add origin https://github.com/Lynn008800/mood-station.git
git push -u origin main
```
3. 在仓库 Settings → Pages → 选择 main 分支 → 保存
